## What I work on

platform used by universities: candidate anonymisation, high-volume
digitisation, on-screen assessment, review workflows and results processing.
99.9% uptime across continuous 20+ day assessment cycles, where an outage
mid-cycle strands assessors and delays an institution's results.

**Database architecture & enterprise reporting** — SQL Server, T-SQL, SSIS and
SSRS across a production estate. 40% reporting performance improvement from an
execution-plan-driven overhaul of legacy T-SQL, and roughly half the manual
audit time removed through Python and SQL automation.

**Multi-tenant SaaS ERP** — my own build. Ten business modules on a two-level
Tenant → Organization model, so one deployment serves many client companies
without a fork per customer. Node.js, TypeScript, Express, PostgreSQL,
React, Vite.

**Security & identity** — OWASP secure coding, JWT with refresh lifecycle,
RBAC and claims-based authorisation, 2FA, audit logging, and security review
of authentication flows.
